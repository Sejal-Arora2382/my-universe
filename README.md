# 🌌 My Universe – Interactive Galaxy Experience

An interactive WebGL galaxy where every visitor can place a star and leave their mark.

Built with:
- Three.js
- Firebase (real-time persistence)
- Vite
- Deployed on Vercel

✨ Every interaction grows the universe.

🔗 Live Demo: (https://my-universe-pink.vercel.app/)

---

## Concept

This project explores emotional interaction design.

Visitors enter a minimal universe, add a star, and trigger a narrative sequence:
- Act 1 – Introduction
- Act 2 – Interaction
- Act 3 – Emotional Response
- Act 4 – Design Philosophy Reveal

The universe expands because someone showed up.
