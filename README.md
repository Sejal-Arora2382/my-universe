# 🌌 My Universe – Interactive Galaxy Experience

An interactive WebGL galaxy where every visitor can place a star and leave their mark.

Built with:
- Three.js
- Firebase (real-time persistence)
- Vite
- Deployed on Vercel

✨ Every interaction grows the universe.

🔗 Live Demo: (https://my-universe-pink.vercel.app/)
